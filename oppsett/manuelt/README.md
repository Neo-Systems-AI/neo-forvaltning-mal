# Det som gjøres for hånd

Deler av oppsettet skriver Neo ikke som fil ennå. Hva det gjelder i denne organisasjonen, står i `ikke-med.md` i
snapshotet (for eksempel behandlingsregler, maler, tagger, arkivoppsettet og tilgangsgruppene). Beskriv dem her som
tekst (én fil per område), så endringer i dem også går gjennom PR og godkjenning. Selve endringen gjøres i Neo, og den
som gjør den, skriver en rad i `beslutninger.md`. Når Neo tar en type med i filene, flyttes den herfra til `oppsett/`.
