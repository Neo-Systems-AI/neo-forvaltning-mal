# Det som gjøres for hånd

Deler av oppsettet har ennå ikke MCP-verktøy i Neo: maler, instrukser, tagger, arkivoppsettet og tilgangsgruppene.
Beskriv dem her som tekst (én fil per område), så endringer i dem også går gjennom PR og godkjenning. Selve endringen
gjøres i Neo, og den som gjør den, skriver en rad i `beslutninger.md`.
